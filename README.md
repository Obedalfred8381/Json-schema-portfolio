# Json-schema-portfolio
## Overview
A collection of advanced JSON annotation projects demonstrating 
schema design, document validation, reconciliation annotation, 
and multi-document entity extraction. Built as part of a 
self-directed data annotation learning programme.

## Projects in this Repository

### 1. Job Application Schema
A complete JSON schema designed from scratch for annotating 
job application forms, including field rules, data type 
validation, and required field enforcement.

Files:
- job_application_schema.json — schema definition
- job_application_sample.json — sample annotation using the schema

Skills demonstrated:
- JSON schema design from scratch
- Field level validation rules
- Data type enforcement
- Required field definition
### 2. Reconciliation Annotation
A reconciliation validation annotation comparing a purchase 
order against an invoice, flagging every discrepancy and 
producing an overall PASS or FAIL status.

Files:
- reconciliation_annotation.json

Skills demonstrated:
- Cross document validation
- Field level reconciliation
- Discrepancy documentation
- Financial QA annotation

---

### 3. Multi Document Annotation
A complex annotation of a contract extract that references 
three external documents, capturing all named entities, 
document references, and entity relationships.

Files:
- multi_document_annotation.json

Skills demonstrated:
- Named entity recognition
- Relationship annotation
- Multi document referencing
- Complex nested JSON structuring
